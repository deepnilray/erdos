# Erdős #203 literature and technique ledger (agent B, 2026-10-23)

Question (site wording, erdosproblems.com/203, quoted from the page fetched 2026-10-23): "Is there an integer m≥1 with (m,6)=1 such that none of 2^k 3^ℓ m+1 are prime, for any k,ℓ≥0?"
The repo uses k,ℓ≥1. A YES for the k,ℓ≥1 form is weaker than a YES for the site form (the site form also forbids primes on the rows ℓ=0 and k=0). Column k=0 is always even, so it only matters for m=1 (3^0·1+1 = 2 is prime, so m=1 is not a YES in the site form). Any finite covering is periodic, so covering-type results do not see the difference.

## E. Net assessment of the literature for the NO side

Nothing beyond EO79 Theorem 2 exists for a *given m*. Every NO-side tool above either (i) works only on average over m (EO79; Romanoff-type second moments; Linnik-type results), or (ii) controls a different quantity (gcd bounds, Zsigmondy, S-units). The only tools that bear on each fixed m are covering-system obstructions, which are on the YES side. A proof that every m has a prime would need primes in a set with O((log X)²) members below X, with an obstruction (parity) that rules out every known sieve.
